# Learning Pygame

This repository contains all the source code files of my journey learning Pygame, organized into a clean project structure.

## Repository Structure

```text
learning_pygame/
├── assets/                  # Game assets and resources
│   ├── fonts/               # Custom TTF fonts
│   ├── images/              # Sprites, backgrounds, textures
│   └── sounds/              # Sound effects and music
├── lessons/                 # Pygame/Python tutorial and guide scripts
│   ├── lesson_01_classes.py # OOP basics (Classes & Objects)
│   └── lesson_02_imports.py # Python modules & imports
├── src/                     # Source files for game projects and prototypes
│   ├── pygame_og_tutorial.py# Original Pygame moving circle tutorial
│   └── window.py            # Clean boilerplate Pygame window template
└── README.md                # Project documentation (this file)
```

## Running the Examples

Make sure you have Pygame installed:
```bash
pip install pygame
```

To run the window template, execute:
```bash
python src/window.py
```
